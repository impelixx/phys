# М5. Физический маятник

## Задача и параметры

Однородный стержень длины $L$ и массы $m$ подвешен за конец. Его отпускают из угла $\varphi_0$ без начальной скорости. Учитывается тяжесть и распределённое вязкое сопротивление; $g=9{,}81$ м/с².

| Параметр | Диапазон в приложении | Обоснование |
|:--|:--|:--|
| Масса $m$, кг | 0,1–100 | Диапазон от лёгкого до массивного образца. |
| Длина $L$, м | 0,1–10 | $L>0$; диапазон позволяет проверить зависимость $T\sim\sqrt L$. |
| Угол $\varphi_0$, ° | 0,1–179 | При $0^\circ$ нет колебаний; при $180^\circ$ верхнее положение неустойчиво и период без трения неограниченно растёт. |
| Сопротивление $\beta$, Н·с/м² | 0–10 | Нуль отключает трение; верхняя часть диапазона позволяет получить апериодическое затухание. |
| Время $t_{\max}$, с | 0,2–50 | Короткий интервал показывает часть движения, длинный — несколько периодов. |

**Выход:** анимация стержня, $\varphi(t)$, период по точкам поворота, сравнение с теорией, графики кинетической, потенциальной и полной энергии. Если полного колебания нет, период не выводится.

## Модель и аналитические проверки

Для однородного стержня $dm=(m/L)\,dr$. Момент инерции и моменты сил относительно оси подвеса:

$$
I=\int_0^L r^2\,dm=\frac{mL^2}{3},\qquad
M_g=-mg\frac L2\sin\varphi,\qquad
M_\beta=-\beta\dot\varphi\int_0^L r^2\,dr=-\frac{\beta L^3}{3}\dot\varphi.
$$

Из $I\ddot\varphi=M_g+M_\beta$ получается уравнение, которое решает программа:

$$
\ddot\varphi+\frac{\beta L}{m}\dot\varphi+\frac{3g}{2L}\sin\varphi=0,
\qquad \varphi(0)=\varphi_0,\quad\dot\varphi(0)=0.
$$

При малом угле $\sin\varphi\approx\varphi$; без трения период равен $T_0=2\pi\sqrt{2L/(3g)}$. При $\beta=0$ и произвольном $\varphi_0<180^\circ$ код сравнивает численное решение с точным периодом $T=4K(\sin^2(\varphi_0/2))/\omega_0$, где $\omega_0=\sqrt{3g/(2L)}$, $K$ — полный эллиптический интеграл первого рода. При малых углах и трении используется $T_\beta=T_0/\sqrt{1-\gamma^2}$, где $\gamma=\beta L/(2m\omega_0)<1$. При $\gamma\geq1$ линейная модель не колеблется.

Проверка энергии: $E=I\dot\varphi^2/2+mgL(1-\cos\varphi)/2$. Подстановка уравнения движения даёт $dE/dt=-\beta L^3\dot\varphi^2/3\leq0$: при $\beta=0$ энергия постоянна, при $\beta>0$ убывает.

## Численный эксперимент

Интегрирование полного нелинейного уравнения: адаптивный DOP853, относительная точность $10^{-10}$, абсолютная $10^{-12}$; для графиков берётся 200 точек/с. Период вычисляется по событиям $\dot\varphi=0$. Если не указано иное: $m=1$ кг, $L=1$ м, $\varphi_0=2^\circ$, $\beta=0$, $t_{\max}=10$ с.

## Проверка и вывод

Тесты сравнивают численный период с $T_0$, точным периодом и линейной теорией с трением; проверяют сохранение энергии без трения, её убывание при $\beta>0$, независимость движения от массы при $\beta=0$ и отсутствие колебаний при сильном затухании. На приведённых опытах зависимость от длины, амплитуды и трения соответствует аналитическим расчётам.
