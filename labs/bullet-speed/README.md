# Скорость пули (баллистический маятник)

Обработка лабораторной работы по рабочей формуле методички

```
u = (M / m) · (d / L) · √(g·L)
```

Два варианта интерфейса, физика и отчёты у них общие:

| | запуск | что это |
|---|---|---|
| **GUI** | `uv run bullet_speed_gui.py` | нативное окно (Qt): формы, таблица выстрелов, живой пересчёт, графики, кнопка «Собрать PDF-отчёт» |
| **Терминал** | `uv run bullet_speed.py` | пошаговый ввод в консоли, в конце сохраняет json + md + pdf + png |
| **Проверка** | `uv run bullet_speed_test.py` | прогон формул, погрешностей, округления и экспорта — на случай правок |

Нужен только [uv](https://docs.astral.sh/uv/) — зависимости прописаны в шапке
скриптов (PEP 723) и ставятся сами. Первый запуск GUI дольше: качается Qt.

## GUI

```bash
cd labs/bullet-speed
uv run bullet_speed_gui.py
```

Окно открывается с демо-данными — просто замените их своими:

- **слева** — параметры установки: M и ΔM, L и ΔL, погрешность весов Δm,
  погрешность отсчёта Δd, g, отклонение при холостом выстреле d₀
  (вычитается из каждого d — поправка на струю воздуха);
- **справа сверху** — таблица выстрелов: серия, масса пули, отклонение;
  колонки `u` и `Δu` считаются на лету. Кнопки «+ выстрел», «− удалить»,
  «Очистить», а **Ctrl+V** вставляет пары чисел «масса отклонение» прямо из
  журнала (по строке на выстрел);
- **справа снизу** — карточки результата по каждой серии (`u = 244 ± 16 м/с`,
  σ, случайная и приборная погрешности, относительная погрешность) и два
  графика: скорость по выстрелам и вклад величин в погрешность;
- если серий две (винтовка / пистолет), появляется карточка сравнения:
  Δ⟨u⟩, Δ/σ_Δ и вывод, достоверно ли различие.

Кнопки сверху: **Демо** (вернуть пример), **Открыть…** (json с прошлого раза),
**Сохранить данные**, **Собрать PDF-отчёт** — PDF сохраняется, рядом кладётся
json с данными, и отчёт сразу открывается в просмотрщике.

## PDF-отчёт

Три страницы без лишней «титульной» шапки — только название работы и дата
тонкой строкой сверху:

1. параметры установки и таблица измерений;
2. результаты по сериям, сравнение серий, бюджет погрешностей (там же обе
   расчётные формулы);
3. графики: скорость по выстрелам, проверка линейности `u ∝ d` с подогнанной
   прямой и диаграмма «что определяет погрешность».

Кириллица и формулы рисуются шрифтом matplotlib, внешних зависимостей нет.

## Терминальный вариант

```bash
uv run bullet_speed.py            # интерактивный ввод
uv run bullet_speed.py --demo     # пример
uv run bullet_speed.py results/data-....json   # пересчёт сохранённых данных
```

Выстрелы вводятся парами «масса пули и отклонение через пробел»: `0.5121 10.4`,
пустая строка заканчивает серию. Флаги: `--outdir DIR`, `--no-files`.

## Как считаются погрешности

Приборная погрешность каждого выстрела — из формулы косвенного измерения:

```
(Δu/u)² = (ΔM/M)² + (Δm/m)² + (Δd/d)² + ¼·(ΔL/L)²
```

(коэффициент ¼ — потому что u ∝ L^(−1/2)).

Случайная погрешность среднего — `t(0.95, n−1) · σ / √n`, где σ — выборочное
СКО. Полная погрешность — квадратичная сумма случайной и приборной; результат
округляется по правилу значащих цифр погрешности.
